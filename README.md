# Soleilina Baby and Co - Prototype Démonstration Client

Ce projet est un prototype interactif indépendant conçu pour présenter la charte graphique pastel, l'ergonomie mobile/desktop, le catalogue et le parcours d'achat à votre client.

## 🚀 Démarrage rapide

1. Ouvrez un terminal dans ce dossier :
```bash
cd "c:\Users\haite\Bureau\Baby Ecom Prototype"
```

2. Installez les dépendances :
```bash
npm install
```

3. Lancez le serveur de développement :
```bash
npm run dev
```

4. Ouvrez votre navigateur sur **http://localhost:3001** (port 3001 configuré pour ne pas entrer en conflit avec votre projet principal sur le port 3000).

## 🎨 Caractéristiques de ce Prototype
- **Design & Couleurs Douces** : Bleu ciel pastel (`#8EBEEC`), Rose guimauve (`#F7B5CD`), Menthe douce (`#A8DDC5`), Fond crème lacté (`#FDFBF9`).
- **Données Fictives Réalistes** : 6 produits phares, 4 catégories, avis clients et notes 5 étoiles.
- **Parcours d'achat complet simulé** :
  - Page d'accueil avec bannières de réassurance et offre de lancement.
  - Page collection avec tri interactif par prix/note.
  - Fiche produit détaillée avec sélecteur de taille, couleur, quantité et bouton direct WhatsApp.
  - Panier avec calcul dynamique de la livraison offerte et test du code promo `BIENVENU10`.
  - Tunnel de paiement one-page avec simulation de validation de commande.
- **Réseaux Sociaux intégrés au Footer** : Instagram, Facebook et TikTok.
